# Family Adventure

Пиксельный платформер про семью: папа, мама и дочка путешествуют по Средиземноморскому побережью.
Вертикальный экран 9:16, играется в браузере телефона и компьютера.

## Герои

Переключаться можно в любой момент (кроме как под водой), на экране всегда один герой.

| Герой | Способность |
|---|---|
| Папа | толкает тяжёлые ящики, запускает механизмы (рычаги) |
| Мама | замедляет время на 5 секунд («поёт»), потом нужен отдых |
| Дочка | в воде превращается в аксолотля и плавает |

## Управление

- Телефон: кнопки ◀ ▶, ПРЫЖОК, кнопка способности; тап по портрету меняет героя.
- Клавиатура: ←/→ или A/D бег, Пробел/↑/W прыжок, E/X/Shift способность, 1/2/3 или Q смена героя.
- Аксолотль: прыжок или ↑ плыть вверх, ↓ вниз, прыжок у поверхности выпрыгнуть из воды.

## Разработка

```bash
npm install
npm run dev      # локальный сервер, открывается и с телефона в той же сети
npm run build    # сборка в dist/
```

Стек: Phaser 3 + TypeScript + Vite. При пуше в `main` GitHub Actions собирает игру и выкладывает её на GitHub Pages
(в настройках репозитория: Settings → Pages → Source: GitHub Actions).

## Структура

- `src/config.ts` размеры экрана, физика, параметры героев
- `src/level.ts` уровень 1, собранный из прямоугольников в тайлах
- `src/art.ts` временная пиксельная графика, нарисованная кодом; заменяется картинками с теми же ключами
- `src/controls.ts` сенсорные кнопки
- `src/scenes/GameScene.ts` игровая логика: герои, способности, враги, HUD
